# NftMantle

NftMantle enables Smart, Decentralized Data Processing through Real-time Node Layer Integration with Dynamic Token Management capabilities.

With NftMantle, you get a lightweight tool that stays out of your way.

**What you get**

- NftMantle enables Smart, Decentralized Data
- Processing through Real-time Node Layer
- Integration with Dynamic Token Management

## Key Features

- NftMantle enables Smart, Decentralized Data
- Processing through Real-time Node Layer
- Integration with Dynamic Token Management

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftMantle.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NftMantle, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
